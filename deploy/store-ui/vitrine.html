Hospedagem Soberana

Hospede frontends e microserviços em Chambers isoladas do Vacuum ou CIDs imutáveis servidos pelo Singularity Event Horizon.

  • Zero dependência de servidores centralizados ou cartão de crédito.
  • Roteamento direto por órbita no Event Horizon (:7474).
  • Proteção sandboxing nativa via Bubblewrap e Linux cgroups.
# Publica qualquer site estático ou binário:
cargo run -p mycelium-cli -- sow --message "meu-site"
# Acesso universal via Singularity:
curl http://127.0.0.1:7474/webapp/

Sustentabilidade Energética
Sclerotium & Ghost Carrier

O nó não precisa ficar ligado 24/7 gastando 200W. Ele pode hibernar em modo escleródio e ser acordado sob demanda via rádio ou rede.

  • Presença lógica delegada a proxies via GhostLease.
  • Despertar seletivo anti-DoS via WakeToken autenticado.
  • Integração com Wake-on-LAN Ethernet e microcontroladores LoRa.
# Gera a GhostLease antes de suspender a máquina:
mycelium sclerotium lease --ttl-minutes 1440
# Dispara impulso para acordar um nó dormente:
mycelium sclerotium wake --target <NodeId> --mac 0c:cc:47:e5:8a:57
