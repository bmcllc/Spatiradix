Como Usar o Git Soberano

        

          O Mycelium dispensa o GitHub e plataformas proprietárias. Os commits são Plots imutáveis replicados diretamente pela DHT e Gossipsub.
        


        
1. Publicar um Projeto Local

        

          mycelium repo publish --dir ./meu-projeto --repository meu-repo --branch main --message "v1.0"
        


        
2. Clonar Qualquer Repositório sem GitHub

        

          mycelium repo clone --cid Qm... --dest ./copia
        


        
3. Validar Código Confinado

        

          mycelium repo validate --cid Qm...
