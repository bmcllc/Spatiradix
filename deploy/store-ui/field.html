Como Usar o TheField (Git Soberano + Signals)

        

          O TheField unifica a forja soberana de repositórios Git P2P e o campo de colaboração por Signals (Merge, Release e Pipelines sem GitHub).
        

        
1. Publicar um Repositório Local

        
mycelium repo publish --dir ./meu-projeto --repository meu-repo --branch main --message "v1.0"

        
2. Clonar Repositório P2P

        
mycelium repo clone --cid Qm... --dest ./copia

        
3. Validar em Vacuum Chamber

        
mycelium repo validate --cid Qm...
